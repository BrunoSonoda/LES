# 🛒 LES - Sistema de E-commerce

Projeto desenvolvido para a disciplina de **Laboratório de Engenharia de Software (LES)** do curso de **Análise e Desenvolvimento de Sistemas** da **FATEC Mogi das Cruzes**.

O objetivo do projeto foi desenvolver um sistema de e-commerce aplicando conceitos de Engenharia de Software, arquitetura em camadas, desenvolvimento Full Stack e integração entre front-end e back-end.

---

# 📚 Sobre o projeto

Este sistema consiste em um **e-commerce de camisetas**, permitindo o gerenciamento de produtos, clientes e demais funcionalidades necessárias para uma loja virtual.

Durante o desenvolvimento foram aplicados conceitos de análise de requisitos, modelagem, desenvolvimento de APIs REST, banco de dados e integração entre cliente e servidor.

---

# 🚀 Tecnologias utilizadas

### Back-end

* Node.js
* Express.js
* Sequelize ORM
* MySQL
* JWT (Autenticação)
* Multer (Upload de imagens)

### Front-end

* React
* React Router
* Redux
* Redux Saga
* Axios
* React Toastify

### Ferramentas

* Git
* GitHub
* Postman
* Insomnia

---

# ⚙️ Funcionalidades

* Cadastro de usuários
* Login com autenticação JWT
* Cadastro de produtos
* Edição de produtos
* Exclusão de produtos
* Upload de imagens
* Listagem de produtos
* Gerenciamento de clientes
* Gerenciamento de endereços
* Gerenciamento de cartões de crédito
* API REST integrada ao front-end

# ▶️ Como executar

## Clonar o repositório

```bash
git clone https://github.com/BrunoSonoda/LES.git
```

## Back-end

```bash
cd backend

npm install

npm run dev
```

## Front-end

```bash
cd frontend

npm install

npm start
```

# 🎯 Objetivo

Este projeto foi desenvolvido como atividade prática da disciplina de **Laboratório de Engenharia de Software (LES)**, com o propósito de aplicar na prática os conhecimentos adquiridos durante o curso de Análise e Desenvolvimento de Sistemas.

O foco foi desenvolver uma aplicação Full Stack utilizando tecnologias modernas para web, integrando front-end, back-end e banco de dados em um único sistema.
